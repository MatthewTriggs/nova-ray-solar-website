# Nova Ray Solar Website

Static HTML/CSS/JS website for Nova Ray Solar, a solar installation business based in Moreleta Park, Pretoria.

## Structure

- `index.html` — Home page
- `about.html` — About the business
- `packages.html` — Full solar package pricing (5 packages, R55,000–R128,000)
- `gallery.html` — Installation photo gallery
- `contact.html` — Contact details and enquiry form
- `css/styles.css` — Site styles
- `js/main.js` — Mobile nav toggle, footer year, contact form handling
- `images/` — Logo and installation photos

## Placeholder content

Search the codebase for `PLACEHOLDER` to find copy the client should confirm before this goes live:

- `about.html` — founding year / years of installer experience
- `contact.html` — site inspection operating hours/days
- `packages.html` — current pricing note (flyer pricing was marked "while stocks last" and should be reconfirmed with the client before publishing)

## Contact form

The enquiry form on `contact.html` currently just confirms submission locally in the browser (no backend). To actually receive enquiries by email, wire it to a form backend such as Formspree, or replace it with a `mailto:` link.
